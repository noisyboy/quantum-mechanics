## 📌 Overview
This repository contains analytical solutions and computational simulations for advanced problems in non-relativistic quantum mechanics. It bridges theoretical derivations with numerical implementations, focusing on visualizing wavepacket dynamics, calculating transition probabilities, and solving the Schrödinger equation for complex potentials.

## 🧮 Numerical Methods Implemented
The simulations leverage both Python and Fortran to balance rapid visualization with high-performance numerical computing. Key algorithms include:
* **Eigenvalue Solvers:** Numerov's method and finite difference schemes for 1D and 3D potentials.
* **Time Evolution:** Runge-Kutta (RK4) and Crank-Nicolson methods for time-dependent wavepacket propagation.
* **Integration Methods:** Simpson's 1/3 rule and Gaussian quadrature for evaluating transition matrix elements and overlap integrals.
* **Root Finding:** Newton-Raphson methods for transcendental energy quantization equations.
